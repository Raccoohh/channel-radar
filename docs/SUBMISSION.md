# Текст для здачі

Добрий день! Надсилаю виконане тестове завдання **Channel Radar**.

Застосунок: https://channel-radar-0o24.onrender.com

Репозиторій: https://github.com/Raccoohh/channel-radar

Сервіс дозволяє додавати публічні Telegram-канали через інтерфейс, регулярно збирає
реальні пости, зберігає історію метрик у PostgreSQL та створює українські AI-дайджести.

Найскладнішим рішенням було забезпечити регулярний збір на безкоштовному хостингу,
який засинає: GitHub Actions будить Render, а стан наступного збору та блокування
зберігаються в незалежній Neon PostgreSQL. Умовні оновлення, lease та fencing token
захищають від дублювання і запису результатів застарілим воркером після перезапуску.
Для AI використано перевірений Gemini Flash-Lite з обмеженням контексту, кешем і
контролем кількості спроб; відмова провайдера не блокує дашборд.
Холодний старт і затримки cron відкрито описані в README.

У репозиторії є міграції, 61 тест без мережі, GitHub CI, ADR, результати production
перевірок і пояснення архітектурних компромісів. Для швидкої демонстрації можна
відкрити вже зібраний канал @durov, змінити період і переглянути історію окремого поста.
Після неактивності перше відкриття безкоштовного Render може зайняти близько хвилини.
